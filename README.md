# Kelime Yıldızı site

Public privacy policy and support pages for the Kelime Yıldızı iOS app, served with GitHub Pages.

- `privacy.html` must stay in step with `App/Resources/PrivacyNotice.md` in the app repo.
- Bracketed values such as `[Yayıncı adı]` are placeholders; fill them in with the same values as `KY_*` in the app's `project.yml`.
